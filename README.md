# Open Source school database

---
This is an open source school database with the following tables:

    1. teachers
    2. students
    3. courses
    4. classes
    5. enrollments
    6. grades
    7. fees
    8. attendance
    9. departments

---
## How to make use of the database

This database can be cloned to your local environment for data science projects in a postresql database management system or alternatively, used for a school management system.

---

### Using it locally

In your computer's terminal, type the following commands:
fyi: this project assumes that you already have git installed in your system, if not, then access this resource for guidance: 
[git installation guide](https://git-scm.com/install)

`git clone git@github.com:r0elcompute/openschool_database.git`

or `https://github.com/r0elcompute/openschool_database.git` for https connections

### Supabase

You can also make use of this database on supabase by simply copying and pasting the raw sql queries into a supabase sql editor.

# Additional information

 - The database contains empty tables and assumes that you can source for your own data for projects
 - The only table with some practice data is the students table and teacher table at most

Feel free to experiment with this project the way you want.
Happy coding!
